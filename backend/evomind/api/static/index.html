    Risk ranking

    Chance of a bug-fixing commit within the horizon, scored on the latest commit. Each file lists the measurements that raise its score most.

    # Band Actions

    Risk is a predicted probability, not a certainty. Fix commits are found by commit-message keywords, then traced back with SZZ (git blame on each fix's parent) to confirm the defect already existed at the training cutoff. Treat scores as a directional signal. "Ask AI" sends that file's source and metrics to Groq's API (a third party) to write a recommendation.

    Coupling

    Import graph parsed from source: 0 edges inside the repository. Instability is efferent ÷ (efferent + afferent); near 0 means many files depend on it, so changes ripple.

    Circular dependencies

    Files that import each other in a cycle. Usually a sign they should be merged or share an extracted piece.
